## 📖 نبذة عن المشروع

**المعزب** هو تطبيق فلاتر (Flutter) يعمل كدليل ذكي للأماكن والفعاليات في مدينة الرياض. يعتمد التطبيق على **الموقع الجغرافي للمستخدم** لترتيب الأماكن والفعاليات من الأقرب إلى الأبعد تلقائيًا دون الحاجة لاختيار أي تصنيف، ويوفر تفاصيل عملية مثل قرب المكان من محطات المترو، السعر، وأوقات العمل — بالإضافة إلى مساعد ذكاء اصطناعي يقترح عليك وجهتك القادمة بناءً على ميزانيتك واهتماماتك.

هذا المشروع هو **مشروع التخرج النهائي** لمعسكر تطوير تطبيقات فلاتر — بوتكامب طويق.

## ✨ المميزات

### 🧭 اكتشاف ذكي مبني على الموقع
- عرض الأماكن والفعاليات القريبة منك تلقائيًا فور فتح التطبيق (بدون اختيار تصنيف)، بالاعتماد على إحداثيات المستخدم وإحداثيات كل مكان.
- تصنيفات سريعة أعلى الصفحة الرئيسية (ثقافي، ترفيهي، مؤتمرات...) مع ترتيب النتائج من الأقرب إلى الأبعد داخل كل تصنيف.
- عرض بيانات مبدئية لكل بطاقة: اسم المكان، مجاني/مدفوع، المسافة عنك، وأقرب محطة مترو.

### 📍 تفاصيل شاملة لكل مكان
- معرض صور، وصف مبسط، والتصنيف الفرعي (متحف، حديقة، ...).
- هل يتطلب حجز؟ وما السعر؟ وما أوقات العمل خلال أيام الأسبوع؟
- قسم مخصص لأقرب محطات المترو مع اسم المسار (خط)، المسافة، ووقت المشي التقريبي لكل محطة.
- رابط مباشر لموقع المكان على الخريطة، ورابط لحجز التذاكر إن وُجد.

### ❤️ التفاعل الشخصي
- **المفضلة**: حفظ الأماكن التي تعجبك للرجوع لها لاحقًا.
- **زياراتي (مزار)**: تسجيل الأماكن التي زرتها فعليًا مع إضافة ملاحظة شخصية وتاريخ الزيارة (اليوم / أمس / تاريخ محدد).

### 🤖 مرشد المعزب — مساعد ذكاء اصطناعي (Gemini AI)
- شات بوت تفاعلي يسألك عن ميزانيتك واهتماماتك ونوع الأماكن التي تفضلها.
- يقترح عليك أماكن مناسبة ويساعدك في التخطيط لجدول زيارتك.

### 🏪 اقتراح الأماكن وحساب الشريك
- **اقترح مكانًا**: أي مستخدم مسجّل يقدر يقترح مكانًا جديدًا (الاسم، الموقع، الرابط الإلكتروني) ليتم مراجعته ونشره للجميع.
- **حساب شريك**: نظام انضمام لأصحاب المنشآت ومنظمي الفعاليات، يتيح لهم مستقبلًا نشر أماكنهم وتحديث بياناتها مباشرة دون انتظار المراجعة، مع شارة "موثّق" على حسابهم. نوعين للشراكة:
  - **منظّم فعاليات**: يقيم فعاليات وأنشطة وينشرها في الدليل.
  - **مالك منشأة**: يملك أو يدير مكانًا ثابتًا ويرغب بإضافته وتحديث بياناته.

### 🔐 الحسابات والإعدادات
- تسجيل الدخول والتحقق من المستخدم عبر Supabase Auth.
- تبديل المظهر (فاتح / داكن / تلقائي).
- تسجيل الخروج، وإدارة الوصول السريع للمفضلة والزيارات من صفحة الحساب.

## 🗄️ قاعدة البيانات

تعتمد قاعدة البيانات على **Supabase (PostgreSQL)** وتتكوّن بشكل أساسي من جدولين مرتبطين بعلاقة **Foreign Key**:

1. **جدول الأماكن / الفعاليات** — يحتوي على كل الأعمدة اللازمة لكل مكان أو فعالية: الاسم، الوصف، الصور، الموقع/الإحداثيات، السعر، الحجز، أوقات العمل، رابط الحجز، إلخ.
2. **جدول التصنيفات** — يستخدم للفرز والفلترة (مثل: ثقافي، ترفيهي، مؤتمرات)، ومرتبط بجدول الأماكن عبر مفتاح أجنبي (Foreign Key) لربط كل مكان بتصنيفه.

> ملفات الهجرة (migrations) الخاصة بقاعدة البيانات موجودة في مجلد [`supabase/migrations`](./supabase/migrations).

## 🤖 مساعد الذكاء الاصطناعي (مرشد المعزب)

ميزة **"مرشد المعزب"** هي شات بوت مبني على **Gemini AI**، يسأل المستخدم عن ميزانيته ونوع الأماكن التي يحبها، ثم:
- يحلل تفضيلاته من الأسئلة والإجابات.
- يقترح عليه أفضل الوجهات المناسبة له.
- يساعده في التخطيط لجدول الزيارة.

## ✅ متطلبات التشغيل

قبل تشغيل المشروع، تأكد من توفر التالي:

- [Flutter SDK](https://docs.flutter.dev/get-started/install) (أحدث إصدار مستقر)
- [Dart SDK](https://dart.dev/get-dart) (يأتي مع Flutter)
- حساب على [Supabase](https://supabase.com) لإنشاء مشروع (Project URL + Anon Key)
- مفتاح API لخدمة [Google Gemini](https://ai.google.dev/)
- محاكي Android/iOS أو جهاز حقيقي لتشغيل التطبيق

## 🚀 طريقة التثبيت والتشغيل

```bash
# 1. استنسخ المستودع
git clone https://github.com/final-prjoect-tuwaiq-flutter/project_flutter.git
cd project_flutter

# 2. ثبّت الحزم (Dependencies)
flutter pub get
```

### إعداد متغيرات البيئة

أنشئ ملف `.env` في جذر المشروع وأضف بيانات الاتصال الخاصة بك:

```env
SUPABASE_URL=your_supabase_project_url
SUPABASE_ANON_KEY=your_supabase_anon_key
GEMINI_API_KEY=your_gemini_api_key
```

> ⚠️ لا تشارك هذه المفاتيح في أي مستودع عام — تأكد من إضافة `.env` إلى ملف `.gitignore`.

### إعداد قاعدة البيانات

1. أنشئ مشروعًا جديدًا في Supabase.
2. طبّق ملفات الهجرة الموجودة في `supabase/migrations` على قاعدة بياناتك (عبر Supabase CLI أو لوحة التحكم مباشرة).
3. فعّل خدمة Authentication من لوحة تحكم Supabase.

### تشغيل التطبيق

```bash
flutter run
```

## 📱 جولة داخل التطبيق

1. **Splash Screen** — شاشة ترحيبية تعرض شعار التطبيق واسمه "المعزب".
2. **الشاشة الرئيسية** — عرض تلقائي للأماكن والفعاليات القريبة منك، مع تصنيفات سريعة (ثقافي، ترفيهي، مؤتمرات) وترتيب حسب المسافة.
3. **صفحة التفاصيل** — كل ما تحتاج معرفته عن مكان أو فعالية: الصور، الوصف، التصنيف، السعر، الحجز، أوقات العمل، أقرب محطات المترو، ورابط الموقع/الحجز.
4. **مرشد المعزب (Chatbot)** — مساعد ذكي يسألك عن تفضيلاتك ويقترح عليك أماكن ويخطط لك.
5. **اقترح مكانًا** — نموذج لإضافة مكان جديد يُراجع قبل نشره للجميع.
6. **حساب شريك** — نموذج انضمام كمنظّم فعاليات أو مالك منشأة.
7. **حسابي** — إدارة المفضلة، الزيارات (مزار)، الانضمام كشريك، والمظهر (فاتح/داكن/تلقائي).
